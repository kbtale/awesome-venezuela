# Security Policy

[Leer en Español](SECURITY.es.md)

## Supported Versions

Awesome Venezuela is a curated list of open-source projects, tools, and technical resources created by Venezuelans. As this repository does not distribute executable binary releases, security considerations apply directly to the repository contents, links, workflows, and community interactions.

| Scope / Component | Supported |
| ----------------- | --------- |
| Curated Content & Links (`README.md`, `README.es.md`) | :white_check_mark: |
| Documentation & Policies | :white_check_mark: |
| Repository Workflows & Automation | :white_check_mark: |
| Third-party Listed Projects | :x: (Contact upstream maintainers directly) |

## Reporting a Vulnerability or Security Concern

The privacy, safety, and security of the community is taken seriously.

If you discover a security vulnerability, malicious link, privacy leak, or repository security concern:

1. **Private Vulnerability Reporting (Preferred)**:
   - Go to the **Security** tab of this repository on GitHub.
   - Click **Report a vulnerability** to open an advisory draft privately.
2. **Alternative Contact**:
   - If GitHub Private Reporting is unavailable, please open a private discussion or reach out to the project maintainer directly via GitHub profile contact.

### Please Do Not:
- **Do not open a public GitHub Issue** for sensitive security vulnerabilities, privacy violations, or malicious link reports.

### What to Include in Your Report:
- A clear description of the issue or concern.
- Relevant links, commits, or affected lines.
- Steps to reproduce or evidence supporting the report.

## Listed Third-Party Projects

Please note that **Awesome Venezuela** is a directory/showcase of independent third-party projects. If you find a security issue within any individual project listed on Awesome Venezuela, please report it directly to the respective repository maintainers according to their own security policies.
